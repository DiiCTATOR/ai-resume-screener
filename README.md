# AI Resume Analyzer (MERN)

A full-stack web application featuring an Express/Node.js backend and a Vite React frontend.

## Project Structure

```
├── backend_ai/       # Express.js API server
├── mern_ai/          # Vite + React client
├── .gitignore        # Git ignore rules for both client and server
├── .gitattributes    # Line ending configuration
```

## Getting Started

### 1. Backend Setup

```bash
cd backend_ai
npm install
cp .env.example .env
npm start
```

### 2. Frontend Setup

```bash
cd mern_ai
npm install
cp .env.example .env
npm run dev
```
